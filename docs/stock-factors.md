# 个股多因子分析

入口：打开个股详情 → 研究卡 → **多因子分析**。A股、港股、美股共享同一组价格与风险计算，基准分别为沪深300、恒生指数、标普500。

当前版本 `stock-price-factors-v1` 是个股价格、风险及量能画像。没有完整财报或可比股票池，因此价值、盈利质量、成长、规模和同行业分位显示为未覆盖。横条表示个股自身历史分位，不是全市场排名、综合评分或涨跌概率。多个动量或风险指标可能相关，不能数票或相加推导结论。

## 数值口径

全部因子排除尚未完成的当日日线，以最新实际完整个股收盘为截止日。价格沿用研究卡的腾讯前复权 / Yahoo 公司行动调整口径，旧缓存和复权降级会显式提示。

| 维度 | 计算 | 完整收盘观察需求 |
|---|---|---|
| 中期动量 | `100 × (P[t−21] / P[t−126] − 1)`，跳过最近21个区间 | 127 |
| 相对强弱 | 最近60个共同完整区间的个股简单收益减基准价格指数收益，单位为百分点 | 61 |
| 波动率 | 60个简单日收益的样本标准差 × √252 × 100 | 61 |
| 市场 Beta | 60个同日收益的协方差 / 基准收益方差；基准方差过小时不可用 | 61 |
| 回撤幅度 | 最近120个区间内收盘价最大峰谷跌幅的绝对值 | 121 |
| 相对量能 | 最近完整日成交量 / 此前20个完整日均量 | 21 |

中期动量采用126→21交易区间窗口，并非复刻 [Kenneth French 的12→2月动量组合](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_mom_factor_daily.html)。Beta 是单一市场基准的历史回归斜率，未构造无风险超额收益，也没有估计多因子回归 Alpha。回撤幅度采用正值，越大表示跌幅越深；原研究卡的最大回撤继续用负值。相对量能没有金额与价差信息，不代表流动性或真实资金流；上游成交量未做统一公司行动调整，拆股等事件可能影响其可比性。

自身因子窗口按有效完整个股日线计数。相对强弱、Beta 必须有连续61个基准交易日对应的实际个股收盘，不跳过缺失日缩短窗口，不填充停牌收益；基准缺失、滞后或共同交易日缺失只降级比较维度。尾部停牌时显示实际个股截止日，不把最后成交延用为新成交。

## 图表与分位

每个维度显示原值及自身历史分位。点击可查看最近60期因子值；缺失处保持断点。分位以此前最多120期同口径值为参考，严格排除当期，至少需要60个有效观察。公式为 `(小于当期的数量 + 0.5 × 等于当期的数量) / 有效观察数 × 100`。并列值使用中位秩，常数序列为50%。不足时保留可计算原值，分位显示待积累；60期是展示门槛，不是统计显著性标准。

历史图是基于当前取得的复权日线回算的指标轨迹，历史公司行动或上游修订可能改变轨迹；这些轨迹不是事前留存的预测，也不能当作样本外收益验证。当前没有收益预测、因子选股、组合回测或因果归因。

## 代码与查询

- `src/domain/stock-factors.js`：无 I/O 的计算、滚动历史、历史分位和覆盖说明。
- 复用 `marketService.research()` 的400日日线与缓存，`/api/research` 在原 `{data,meta}` 响应的 `data.factorAnalysis` 中返回结果，不增加上游查询或单独缓存。
- `public/stock-factors.js`：研究卡内的两个视图、历史分位和 ECharts 走势图；数据请求沿用 `modal.researchReq` 防止旧股票响应覆盖新股票。
- AI 的 `get_research_card` 和自动研究证据保留紧凑因子事实，移除图表历史；个股多因子、动量和 Beta 问句在第一次模型请求前注入。财务因子专问不误触发价格研究卡。
